# SOORITRAVELS

SOORITRAVELS is a PHP-based travel booking system with a simple admin panel and REST-like API endpoints for managing destinations, packages, services, media galleries, and bookings.

---

## 🚀 Key Features

- Public website with destinations, packages, services, gallery, and testimonials
- Booking system with create/update functionality
- Admin panel for managing content, bookings, and media
- REST-like API endpoints for frontend and external clients
- File-based media uploads for images and assets

---

## 🛠️ Tech Stack

- PHP (Vanilla PHP)
- MySQL / MariaDB
- HTML, CSS, JavaScript
- Apache / Nginx or PHP built-in server

---

## 📦 Requirements

- PHP 7.4+
- MySQL or MariaDB
- Web server (Apache/Nginx) or PHP built-in server
